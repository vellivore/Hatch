# Hatch

Windows 用 hosts ファイル管理ツール。グループ・プリセットによる一括切り替えに対応。

## ダウンロード

**[最新版をダウンロード](https://github.com/vellivore/Hatch/releases/latest)**

`Hatch.exe` をダウンロードして実行するだけで使えます。インストール・.NET ランタイム不要です。
管理者権限が必要です（hosts ファイルの書き換えのため）。

## 機能

| 機能 | 説明 |
|------|------|
| エントリ管理 | hosts エントリの追加・編集・削除・有効/無効切り替え |
| 階層グループ | `/` 区切りで最大3階層（大区分/中区分/小区分）。hosts の行末にタグとして保存 |
| プリセット | 有効にするグループの組み合わせを保存し、一括で切り替え |
| 競合の表示 | 同じホスト名が複数の行で有効なとき、一覧に ⚠ を付けステータスに件数を表示 |
| タスクトレイ | 常駐してプリセットを右クリックで即切り替え |
| テキスト編集 | hosts ファイルを直接テキスト編集 |
| バックアップ/リストア | hosts ファイルのバックアップと復元 |
| 自動バックアップ | 書き込みのたびに直前の hosts を退避（直近 20 世代）。トレイの「直前の状態に戻す」で復元 |
| DNS フラッシュ | 切り替え時に `ipconfig /flushdns` を自動実行 |

### ショートカット

| キー | 動作 |
|------|------|
| Ctrl+S | 適用（hosts に書き出し） |
| F5 | 最新化（hosts を再読み込み） |

## グループのタグ記法

グループは hosts の各行の行末コメントの先頭に `[大区分/中区分/小区分]` の形で書きます。
タグの後ろに続く文字はコメントとして扱います。無効（コメントアウト）の行も同じです。

```
10.0.0.1 app.example.com # [業務/案件A/環境A] 検証環境
# 10.0.0.2 app.example.com # [業務/案件A/環境B]
```

- 行末コメントが `[` で始まり `]` を含むとき、最初の `]` までをグループとして読みます。`]` がなければ全体がコメントです
- Hatch が書き出すときは、タグを常にコメントの先頭に置きます
- 入力画面では、コメントに `#` を含めることと、コメントを `[...]` で始めることはできません（行やタグが崩れるため）
- グループ情報は hosts だけに保存されるので、hosts をそのまま別の PC に持っていってもグループが残ります

## プリセット

プリセットは「有効にするグループ」の一覧です。切り替えると、グループが付いた行のうちプリセットに含まれるものを有効、それ以外を無効にします。
グループのない行と localhost の行は変更しません。

- グループは前方一致で扱います。`業務/案件A` を含むプリセットは `業務/案件A/環境A` や `業務/案件A/環境B` も有効にします
- プリセット管理画面では、親グループにチェックを入れると子グループも含まれることが分かるよう、子が淡色のチェック済みで表示されます
- 「すべて無効」を選ぶと、グループが付いた行をすべて無効にします
- 一覧に未保存の変更があるときに切り替えると、「適用して切替 / 破棄して切替 / キャンセル」を確認します
- タスクトレイからの切り替えは、未保存の変更があると行わず、通知でお知らせします
- プリセットを選んだときだけ hosts に書き込みます。プリセットの編集・削除だけでは hosts は変わりません

## 自動バックアップと書き込みの安全策

hosts への書き込み（適用・プリセット切替・テキスト編集・リストア・直前の状態に戻す）はすべて同じ手順で行います。

1. 書き込み前の hosts を `%LOCALAPPDATA%\Hatch\backups\hosts.yyyyMMdd-HHmmss.txt` に退避します。直近 20 世代を残し、古いものから削除します
2. hosts と同じフォルダの一時ファイルに書き出し、hosts と置き換えます。途中で失敗しても hosts が空になりません
3. 書き込んだ hosts を読み戻して内容を照合します。一致しなければ退避したファイルに戻し、エラーを表示します

タスクトレイの「直前の状態に戻す」は、最新の退避ファイルを hosts に書き戻して DNS キャッシュをフラッシュします。
戻す前の状態も退避されるので、もう一度実行すると戻す前に戻ります。

## 設定ファイルの場所

設定（ウィンドウ位置・プリセット）は `hatch-config.json` に保存します。

- `Hatch.exe` と同じフォルダに `hatch-config.json` があれば、そのファイルを読み書きします（USB メモリ等で持ち歩く使い方向け）
- なければ `%LOCALAPPDATA%\Hatch\hatch-config.json` を使います
- exe の横で使いたい場合は、exe と同じフォルダに `hatch-config.json` という名前のファイル（空でも可）を置いてください

## v1.x からの移行

v1.x はグループを `hatch-config.json` の `GroupAssignments` に保存していました。v2.0 はグループを hosts のタグに保存します。

1. v2.0 を初めて起動すると、`GroupAssignments` のグループをタグのない行に当てはめ、「旧設定からグループを移行しました。適用で hosts に保存されます」と表示します。この時点では hosts は書き換えません
2. 適用（Ctrl+S）またはプリセット切替で hosts に書き込むと、グループがタグとして hosts に保存され、設定ファイルから `GroupAssignments` を削除します

v1.x の設定ファイルは exe と同じフォルダにあるので、そのまま同じフォルダで v2.0 を起動すれば引き継がれます。

## 開発者向け

実際の hosts を触らず、UAC なしで画面の動作を確認するためのコマンドライン指定です。

| 指定 | 動作 |
|------|------|
| `--hosts <path>` | 指定したファイルを hosts として読み書きします。自動バックアップは `%LOCALAPPDATA%\Hatch\backups\dev\` に保存します。タイトルバーに `[dev: <path>]` を表示します |
| `--no-elevate` | 管理者への自己昇格をしません。`--hosts` と一緒に指定したときだけ有効で、単独では無視します |
| `--config <path>` | 指定したファイルを設定ファイルとして使います |

```
Hatch.exe --hosts .\test-hosts.txt --config .\test-config.json --no-elevate
```

主なボタン・入力欄・一覧には UI Automation 用の `AutomationId` を付けています（例: `PresetComboBox`・`ApplyButton`・`EntryListView`・`SwitchDiscardButton`）。

`tools/smoke/smoke.ps1` は、この指定で起動した Hatch を UI Automation で操作し、一時 hosts と一時設定に対して移行・プリセット切替・バックアップ世代・二重起動を確認します。

```
pwsh -File tools\smoke\smoke.ps1 -Exe .\publish\Hatch.exe
```
